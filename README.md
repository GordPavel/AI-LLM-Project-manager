# AI LLM Project manager

## О проекте

Бот автоматизирует рутинные задачи проектного менеджера через Telegram: отслеживает статусы задач в таск-менеджере, отправляет персонализированные пинги участникам, принимает отчёты о завершении работ и управляет контекстом обсуждений. Встроенный LLM обрабатывает естественный язык, обеспечивая удобное взаимодействие без необходимости перехода в таск-менеджер или системы документации.

В качестве таск-менеджера и системы документации используются Trello и Bookstack. Благодаря применению архитектурного паттерна Adapter, переход на другие системы (например, Jira/Confluence) требует минимальных изменений.

Что планируется добавить в будущем:
- Контекстные диалоги
- Автосоздание задач
- Дайджесты и отчеты
- Telegram-клавиатура
- Контроль автообновления

## Команды
На данный момент в боте реализованны следующие команды

### /set_config <config>
Задаёт глобальный контекст или настройки бота (например, проект, команда, стиль взаимодействия).

### /status_task <task_id>
Получает актуальный статус задачи из таск-менеджера по её идентификатору.

### /set_ping <описание>
Cоздаёт напоминание для участников задачи. Достаточно указать: задачу, время/расписание и список пользователей (например, «пингануть @ivan и @maria по задаче TSK-123 завтра в 10:00»). LLM сама извлечёт параметры.

### /response_ping <описание>
Отправляет отчёт по пингу: указывается статус задачи (например, «готово», «застрял», «на проверке»). Бот прекращает пинговать, если задача завершена. Формулировка свободная — LLM определит намерение.

### /delete_ping <ping_id>
Удаляет активный пинг по его идентификатору.

## Использование

Запуск проекта
1. Построить образ приложения (если исходники изменены)
```
docker compose build
```

2. Поднять сервисы
```
docker compose up -d
```

Пересборка при изменении кода
```
docker compose down
docker compose build
docker compose up -d
```
